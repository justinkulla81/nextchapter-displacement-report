# Edition-to-edition change record (standing requirement from the October 2026 edition)

Every edition after September 2026 includes a short "What changed this edition" table, and this repository keeps the detailed log.

## Reporting period
Calendar month, first through last day, unless a source or design requires otherwise. Each edition states separately:
the reference period, the publication date, and the date through which source data were available. Partial-month data are never silently mixed with full-month data.

## What must be logged (each material change)
1. Section additions (sections, exhibits, analytical features)
2. Section subtractions (removed, materially shortened or consolidated)
3. Data-source changes (new, discontinued, replaced, version or vintage changes)
4. Measurement changes (definitions, universes, denominators, classifications, time windows, inclusion rules)
5. Methodology changes (statistical method, seasonal adjustment, weighting, imputation, estimation, sampling, coding, missing/suppressed data)
6. Revisions (source-data revisions, NextChapter recalculations, error corrections, replication/validation changes)
7. Interpretive changes (conclusions, terminology, claims strengthened/weakened/removed, new caveats)

## Table format
| Change | Type | Previous edition | Current edition | Reason | Historical impact |
|---|---|---|---|---|---|

For methodology changes: old method → new method → reason → effect on historical results. If prior-period results change, publish the revised historical series and mark the break. If they do not, say so explicitly. Never present a recalculated history as though it had always been computed that way.

## September 2026 edition
First edition; not retrofitted. Its in-month revisions (v1.0–v1.7) are in CHANGELOG.md and the report's version log.
